# LETHE — HERO FLOW (90 seconds)
Crypto-native AI agent. Your on-chain style/life, remembered.
Memory you OWN on Walrus/MemWal — portable across apps, verifiable, revocable.
Track: Walrus (AI agent verifiable memory) — Sui Overflow 2026 (deadline Jun 21)

The 90s decides everything. Only features visible here get built bulletproof.

## 0:00–0:15 — IN (zero friction; your memory is born)
- Screen: landing -> "Sign in with Google"
- User: taps -> zkLogin -> in. No wallet, no seed, no gas.
- Under hood: Memory object minted on Sui (owned by user) + MemWal store init on Walrus. Gasless (Enoki sponsored tx).
- Why: normie on-ramp + memory is a user-OWNED on-chain object from second one.

## 0:15–0:40 — IT LEARNS YOU (crypto-native memory)
- Screen: chat with Lethe (optional: link a wallet address read-only).
- User: talks crypto — "momentum trader, hate leverage, bullish SUI, aped X at $Y". Agent acks + remembers.
- Under hood: each memory = semantic entry written to MemWal on Walrus, referenced by user's Sui Memory object.
- Why: a real personal crypto profile, every piece stored on Walrus, owned by the user.

## 0:40–1:05 — IT FOLLOWS YOU (money shot: portability)
- Screen: open a SECOND, different Lethe-powered agent (e.g. portfolio/alerts) it has never seen.
- User: asks "what's my style?" -> 2nd agent ALREADY knows (momentum, no leverage, bullish SUI) without being told.
- Why: THE differentiator. Memory is the USER's, on Walrus — not locked in app #1. ChatGPT/Claude can't do this. MemWal thesis, live.

## 1:05–1:30 — YOU OWN IT (verifiable + revocable)
- Screen: "Your Memory" view — each entry linked to Walrus blob id + Sui object. One tap -> Sui Explorer / Walrus (judge verifies live).
- User: revoke app #2's access -> ask again -> it no longer knows you.
- Why: ownership is REAL. Verifiable (can't be secretly altered) + user-controlled access (revoke = forget).

## FEATURES IN HERO FLOW (ship bulletproof)
1. zkLogin (Google) -> owned Memory object on Sui, gasless mint
2. Chat that writes crypto memories to MemWal on Walrus
3. Cross-app portability: 2 surfaces reading the SAME owned memory  <- THE demo
4. "Your Memory" view: each entry -> Walrus blob + Sui object (judge-verifiable)
5. Access control: grant/revoke an app's read access (revoke = forget, live)

## FEATURES NOT IN HERO FLOW (skip/defer)
- Full on-chain indexer / deep wallet analytics (thin holdings fetch for flavor only)
- Token / payments / monetization (Distribution > Revenue; mention as path)
- Mobile app (web demo; mainnet + mobile = roadmap)
- Heavy multi-agent orchestration (one extra surface is enough)
- Shared/public memory (antimemetics hook) — build ONLY if hero flow bulletproof + time spare

## DECISION RULE (sacred)
"Visible in the 90-second judge experience?"
- YES + bulletproof -> ship
- YES but risks polish -> don't ship
- NO -> don't ship, no matter how cool
The portability money shot (0:40–1:05) is what wins. If anything threatens it, cut the other thing.
